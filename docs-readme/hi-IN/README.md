### 8 हैंड्स-ऑन प्रोजेक्ट्स (Projects)

1. **प्रोजेक्ट 01**: केवल प्रॉम्प्ट बनाम नियम-पहले (Baseline vs Minimal Harness)
2. **प्रोजेक्ट 02**: एजेंट-रीडेबल वर्कस्पेस (Agent-readable Workspace)
3. **प्रोजेक्ट 03**: मल्टी-सेशन निरंतरता (Multi-session Continuity)
4. **प्रोजेक्ट 04**: रनटाइम फीडबैक और स्कोप कंट्रोल (Runtime Feedback & Scope Control)
5. **प्रोजेक्ट 05**: सेल्फ-वेरिफिकेशन और रोल सेपरेशन (Self-verification)
6. **प्रोजेक्ट 06**: कम्पलीट हार्नेस कैपस्टोन (Complete Harness Capstone)
7. **प्रोजेक्ट 07**: पहला ऑटोमेटेड लूप (Loop Engineering First Loop)
8. **प्रोजेक्ट 08**: वर्कफ़्लो को ग्राफ़ में बदलें (Graph Engineering First Graph)

## 🚀 लोकल डेवलपमेंट (Local Dev)

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/walkinglabs/learn-harness-engineering.git
cd learn-harness-engineering

# डिपेंडेंसीज़ इंस्टाल करें
npm install --allow-remote=all

# डॉक्स साइट लोकल में चलाएँ
npm run docs:dev

# एंकर मैप अपडेट करें
npm run anchors:build
npm run anchors:check

# प्रोडक्शन बिल्ड चेक करें
npm run docs:build
```
