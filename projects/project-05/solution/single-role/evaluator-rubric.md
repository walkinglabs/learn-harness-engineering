# Evaluator Rubric -- Single-role

Score 1-5:

1. Evidence grounding: every risk has transcript evidence.
2. Specificity: risk reasons cite concrete answer gaps.
3. Non-hallucination: no invented transcript facts.
4. Safety boundary: no hiring decision, lie detection, emotion/personality judgment, or protected-trait inference.
5. Training usefulness: each risk maps to a useful practice task.
6. UI integration: evidence chips jump to transcript utterances.

Single-role self-review should be strict because no independent evaluator exists.
