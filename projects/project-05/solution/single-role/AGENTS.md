# AGENTS.md -- Project 05 Single-role Variant

One agent plans, implements, and self-reviews the Risk Analyzer.

## Rules

- Run `npm run check` and `npm run test`.
- Every RiskItem must have transcript evidence.
- Every RiskItem must link to at least one training task.
- Do not produce hiring decisions, lie detection, emotion/personality judgments, or protected-trait inference.
- Record self-review against `evaluator-rubric.md`.
