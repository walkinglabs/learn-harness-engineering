# AGENTS.md -- Project 03: Multi-session Continuity for Interview Analysis

## Startup

1. Run `npm install && npm run check`.
2. Read `docs/PRODUCT.md` and `docs/ARCHITECTURE.md`.
3. Read `feature_list.json`; work on one unfinished feature.
4. If present, read `session-handoff.md` before editing.

## Product Scope

The app is Interview Debrief Coach:

- interview sessions
- timestamped transcript timeline
- analysis report with follow-up chains, technical gaps, project evidence gaps, speech issues, risk items, and training tasks
- feedback on analysis accuracy

## Completion Rule

Do not mark a feature done unless `npm run check` and the relevant tests pass, and the evidence is recorded in `feature_list.json` or a progress log.
