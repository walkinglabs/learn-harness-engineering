# AGENTS.md -- Project 06: Complete Interview Debrief Harness Capstone

## Startup Rules

1. Read this file.
2. Run `npm install && npm run check`.
3. Run `npm run test`.
4. The app should launch with `npm run dev`.

## Project Description

This is the capstone for Learn Interview Harness Engineering. The product is Interview Debrief Coach:

- transcript import
- interview session library
- transcript timeline
- follow-up chain analysis
- technical depth gaps
- project evidence gaps
- speech issues
- risk report
- training plan
- feedback
- local storage
- structured logs

## Safety Boundary

The app coaches candidates after interviews. It must not rank candidates, recommend hire/reject decisions, infer protected traits, detect emotion, judge personality, or claim someone is lying.

## What to Build

The starter intentionally has a weak harness. The solution should add feature_list.json, init.sh, session handoff, clean-state checklist, benchmark, cleanup scanner, architecture checks, reliability docs, and quality tracking.
