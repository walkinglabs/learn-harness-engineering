# Project 06: Complete Interview Debrief Harness Capstone

완전한 Interview Debrief Coach 제품과 완전한 하네스를 만들고, 약한 하네스와 강한 하네스의 benchmark 결과를 비교합니다.

## 디렉터리 안내

| 디렉터리 | 의미 |
|------|------|
| `starter/` | 제품은 대체로 동작하지만 하네스가 의도적으로 약하고 restart / benchmark artifacts가 부족합니다. |
| `solution/` | 완전한 제품, 완전한 하네스, benchmark, cleanup scanner, evaluator rubric, quality document가 포함된 참조 구현. |

## 포함 기능

- timestamped transcript import
- optional audio upload entry with mock transcription only
- interview sessions 생성 및 관리
- transcript timeline and speaker correction
- follow-up chain analysis
- technical depth gaps and project evidence gaps
- speech issues, risk report, training plan
- timestamped evidence jumps and feedback
- local storage, structured logs, benchmark, cleanup scanner
