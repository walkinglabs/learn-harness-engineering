# Product -- Interview Debrief Coach

Interview Debrief Coach is a local-first Electron app for candidates reviewing interviews after the session.

## User Flow

1. Create or import an interview session.
2. Import transcript or mock-transcribed audio.
3. Parse speaker, timestamp, and utterance.
4. Segment interviewer follow-up chains.
5. Generate technical gaps, project evidence gaps, speech issues, risk items, and training tasks.
6. Click evidence chips to jump to transcript utterances.
7. Save feedback on analysis accuracy.
