# Project 06：Complete Interview Debrief Harness Capstone

构建完整 Interview Debrief Coach 产品和完整 harness，并对比弱 harness 与强 harness 的 benchmark 结果。

## 目录说明

| 目录 | 含义 |
|------|------|
| `starter/` | 产品大体可用，但 harness 故意较弱，缺少关键 restart / benchmark artifacts。 |
| `solution/` | 参考实现：完整产品、完整 harness、benchmark、cleanup scanner、evaluator rubric、quality document。 |

## 覆盖功能

- 导入带时间戳 transcript
- 可选音频上传入口，但只使用 mock transcription
- 创建和管理 interview sessions
- transcript timeline 与 speaker correction
- follow-up chain analysis
- technical depth gaps 与 project evidence gaps
- speech issues、risk report、training plan
- 时间戳 evidence 跳转与 feedback
- 本地存储、结构化日志、benchmark、cleanup scanner
