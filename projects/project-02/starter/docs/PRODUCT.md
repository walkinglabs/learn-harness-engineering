# Product -- Interview Debrief Coach

Interview Debrief Coach is a local-first Electron app for candidates who want to review technical interviews after the session.

## Core Flow

1. Create or import an interview session.
2. Import a timestamped transcript.
3. Parse speaker, timestamp, and utterance.
4. Display transcript timeline.
5. Generate a debrief report with timestamped evidence.
6. Save feedback on whether an analysis item is accurate.

## Safety Boundary

The app coaches the candidate. It must not rank candidates, recommend hire/reject decisions, infer protected traits, detect emotion, judge personality, or claim someone is lying.
