# AGENTS.md -- Project 01 Interview Debrief Solution

## Goal

Build the minimal Interview Debrief Coach app with a rules-first harness.

## Startup

1. Run `npm install`.
2. Run `npm run check`.
3. Run `npm run test`.
4. Work only on the selected feature in `feature_list.json`.

## Product Rules

- Show interview sessions, transcript timeline, and debrief summary.
- Use fixture transcripts.
- Do not call real LLMs or real transcription APIs.
- Every debrief item must point to timestamped transcript evidence.
- Do not implement hiring decisions, candidate ranking, lie detection, emotion/personality judgment, or protected-trait inference.
