# प्रोजेक्ट 01: बेसलाइन बनाम न्यूनतम हार्नेस (Baseline vs Minimal Harness)

तुलना कीजिए कि एक कमज़ोर हार्नेस (सिर्फ प्रॉम्प्ट) और एक स्पष्ट हार्नेस (रूल्स फाइल्स + वेरिफिकेशन मैकेनिज्म) AI कोडिंग एजेंट के टास्क पूरे करने की दर पर कितना बड़ा असर डालते हैं।

## डायरेक्टरी गाइड

| डायरेक्टरी | मतलब |
|------|------|
| `starter/` | **शुरुआती बिंदु**: सिर्फ एक अस्पष्ट `task-prompt.md`, न कोई `AGENTS.md` और न ही `feature_list.json`। यह "कमज़ोर हार्नेस" वर्ज़न है जो आप एजेंट को देते हैं। |
| `solution/` | **रेफरेंस इम्प्लीमेंटेशन**: वही ऐप कोड, लेकिन पूरे हार्नेस फाइल्स के साथ (`AGENTS.md`, `feature_list.json`, `init.sh`, `claude-progress.md`)। यह "स्पष्ट हार्नेस" वर्ज़न है। |

## इस्तेमाल कैसे करें

```sh
# 1. स्टार्टर (कमज़ोर हार्नेस) के साथ एजेंट टास्क चलाएँ
cd starter
npm install
# Claude Code / Codex को task-prompt.md का कंटेंट प्रॉम्प्ट के रूप में दें
# एजेंट से कहें: विंडो स्टार्टअप, डॉक्यूमेंट लिस्ट, QA पैनल और डेटा डायरेक्टरी पूरा करे
# इस रन के दौरान एजेंट को solution फाइल्स न दिखाएँ।

# 2. सॉल्यूशन (स्पष्ट हार्नेस) के साथ वही टास्क चलाएँ
cd ../solution
npm install
# एजेंट से कहें कि कोड छूने से पहले AGENTS.md, init.sh, feature_list.json,
# और claude-progress.md को पढ़े।

# 3. दोनों नतीजों की तुलना करें
# - क्या टास्क पूरा हुआ?
# - कितनी बार रिट्राई करना पड़ा?
# - क्या एजेंट ने समय से पहले "हो गया" बोल दिया?
```
