# 欢迎来到项目实战

这里是 Learn Interview Harness Engineering 的动手实践部分。仅仅阅读讲义是不够的，你需要亲自构建 Interview Debrief Coach 应用，并观察 Codex 或 Claude Code 等 Agent 在不同 harness 规则下的真实表现。

## 项目概览

本课程包含 6 个围绕同一个 Electron AI 面试复盘产品展开的渐进式项目：

1. **提示词驱动 vs 规则驱动**：对比一个纯 Prompt 驱动的 Agent 和带有基础 Harness 的 Agent 在表现上的差异。
2. **让项目可读并接住上次工作**：学习如何重构代码仓库结构，使其对 AI 更加友好，并建立工作交接机制。
3. **跨会话工作连续性**：设计状态文件和初始化脚本，让 Agent 可以在多次对话中断后无缝恢复工作。
4. **运行反馈与结构控制**：围绕 transcript 解析、分段和分析行为加入检查。
5. **Evaluator 循环与角色分离**：建立针对时间戳证据和复盘质量的独立评审机制。
6. **完整面试复盘 Harness**：搭建最终的、可观测的端到端 Agent 工作环境。

产品边界：这是候选人侧的面试后复盘教练，不做候选人排名、不提供录用/拒绝建议、不推断受保护特征、不识别情绪、不做人格判断，也不判断任何人是否撒谎。

## 如何进行

每个项目文件夹中通常包含：
- `starter/`：你的起始工作区。
- `solution/`：参考的最终实现（如果你卡住了可以参考）。
- 相关的指导文档，说明本次任务的具体背景和目标。

请使用你习惯的 AI Coding Agent（如 Claude Code、Cursor、Trae 等）在每个项目的 `starter/` 目录下完成任务。
