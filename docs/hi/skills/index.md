# स्किल्स (Skills)

इस डायरेक्टरी में कोर्स के साथ आने वाली बंडल्ड AI एजेंट स्किल्स शामिल हैं। स्किल्स असल में सेल्फ-कंटेन्ड प्रॉम्प्ट और टूल टेम्पलेट्स होती हैं जिन्हें AI कोडिंग एजेंट्स (जैसे Claude Code, Codex, Cursor, Windsurf आदि) में लोड करके उनसे खास इंजीनियरिंग टास्क्स करवाए जा सकते हैं।

## harness-creator

AI कोडिंग एजेंट्स के लिए एक प्रोडक्शन-ग्रेड हार्नेस इंजीनियरिंग स्किल। यह आपको 5 मुख्य हार्नेस सबसिस्टम्स बनाने, उनका मूल्यांकन करने और उन्हें बेहतर बनाने में मदद करती है: **निर्देश (Instructions), स्थिति (State), सत्यापन (Verification), दायरा सीमा (Scope Boundaries), और सत्र जीवनचक्र (Session Lifecycle)**।

### यह क्या करती है? (What It Does)

- **शुरुआत से हार्नेस तैयार करना** — `AGENTS.md`, फ़ीचर लिस्ट्स, और वेरिफिकेशन वर्कफ़्लोज़ बनाना।
- **मौजूदा हार्नेस का ऑडिट और सुधार** — पाँच सबसिस्टम्स के आधार पर प्राथमिकता-वार सुधारों का विश्लेषण।
- **मल्टी-सेशन निरंतरता डिज़ाइन करना** — मेमोरी पर्सिस्टेंस, प्रोग्रेस ट्रैकिंग, और क्लीन हैंडऑफ प्रक्रियाएँ।
- **प्रोडक्शन पैटर्न्स लागू करना** — कॉन्टेक्स्ट बजटिंग, टूल सेफ्टी, और मल्टी-एजेंट कोऑर्डिनेशन।

### तुरंत शुरू करें (Quick Start)

इस स्किल की फाइल्स रिपॉजिटरी में [`skills/harness-creator/`](https://github.com/walkinglabs/learn-harness-engineering/tree/main/skills/harness-creator) पर उपलब्ध हैं।

```bash
npx skills add walkinglabs/learn-harness-engineering --skill harness-creator
```

Claude Code के साथ इस्तेमाल करने के लिए, `skills/harness-creator/` डायरेक्टरी को अपने प्रोजेक्ट के स्किल्स पाथ में कॉपी करें, या अपने एजेंट को सीधे इसकी `SKILL.md` फ़ाइल का रेफरेंस दें।

### रेफरेंस पैटर्न्स (Reference Patterns)

इस स्किल में 7 केंद्रित संदर्भ दस्तावेज़ शामिल हैं:

| पैटर्न | कब इस्तेमाल करें |
|---------|-----------------|
| Memory Persistence | जब एजेंट सेशन्स के बीच संदर्भ भूलने लगे |
| Skill Runtime | दोबारा इस्तेमाल होने वाले वर्कफ़्लोज़ को स्किल के रूप में पैकेज करना |
| Context Engineering | कॉन्टेक्स्ट विंडो का बजट संभालना और Just-In-Time लोडिंग |
| Tool Registry | टूल सेफ्टी और कॉन्करेंसी कंट्रोल सुनिश्चित करना |
| Multi-Agent Coordination | समानांतर काम (Parallelism) और स्पेशलाइज़ेशन वर्कफ़्लोज़ |
| Lifecycle & Bootstrap | हुक्स, बैकग्राउंड टास्क्स, और इनिशियलाइज़ेशन चेकलिस्ट |
| Gotchas | 15 छुपे हुए फेलियर मोड्स और उनके ठोस समाधान |

### टेम्पलेट्स (Templates)

इस स्किल में इस्तेमाल के लिए रेडीमेड टेम्पलेट्स मौजूद हैं:

- `agents.md` — स्पष्ट नियमों के साथ `AGENTS.md` का ढाँचा
- `feature-list.json` — JSON Schema + फ़ीचर लिस्ट का उदाहरण
- `init.sh` — स्टैंडर्ड इनिशियलाइज़ेशन स्क्रिप्ट
- `progress.md` — सेशन प्रोग्रेस लॉग टेम्पलेट
- `session-handoff.md` — सेशन हैंडऑफ टेम्पलेट

### स्क्रिप्ट्स (Scripts)

स्किल में तीन उपयोगिता स्क्रिप्ट्स शामिल हैं:

- `scripts/create-harness.mjs` — किसी भी प्रोजेक्ट डायरेक्टरी में हार्नेस फाइल्स स्वतः जनरेट करें
- `scripts/validate-harness.mjs` — मौजूदा हार्नेस का 5 सबसिस्टम्स पर ऑडिट करें
- `scripts/run-benchmark.mjs` — एजेंट के प्रदर्शन की तुलना करने के लिए बेंचमार्क चलाएँ

```bash
# हार्नेस जनरेट करें
node skills/harness-creator/scripts/create-harness.mjs --target /path/to/project

# हार्नेस का ऑडिट करें
node skills/harness-creator/scripts/validate-harness.mjs --target /path/to/project
```

### यह स्किल कैसे बनाई गई (How This Skill Was Built)

`harness-creator` को इस कोर्स के लेक्चर्स में सिखाए गए सिद्ध सिद्धांतों पर बनाया गया है:

- **लेक्चर 2 & 3**: पाँच सबसिस्टम्स और रिपॉजिटरी को एकमात्र सच बनाना।
- **लेक्चर 4**: मोनोसिस्टम इंस्ट्रक्शन्स की जगह मॉड्यूलर संरचना।
- **लेक्चर 5 & 12**: मल्टी-सेशन निरंतरता और क्लीन हैंडऑफ चेकलिस्ट।
- **लेक्चर 6**: इनिशियलाइज़ेशन का अलग फेज़।
- **लेक्चर 7 & 8**: स्कोप सीमाएँ और फ़ीचर लिस्ट्स प्रिमिटिव्स।
- **लेक्चर 9 & 10**: मल्टी-लेयर टर्मिनेशन और एंड-टू-एंड वेरिफिकेशन।
