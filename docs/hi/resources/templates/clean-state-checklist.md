# क्लीन स्टेट चेकलिस्ट (Clean State Checklist)

- [ ] मानक स्टार्टअप पाथ अभी भी काम कर रहा है (`./init.sh` सफल है)।
- [ ] मानक सत्यापन पाथ सफलतापूर्वक चलता है (`npm test` पास है)।
- [ ] वर्तमान प्रगति प्रोग्रेस लॉग में दर्ज है।
- [ ] फ़ीचर स्थिति दर्शाती है कि क्या वास्तव में पास है बनाम क्या असत्यापित है।
- [ ] कोई भी आधा-अधूरा कदम बिना दस्तावेज़ीकरण के नहीं छोड़ा गया है।
- [ ] अगला सत्र बिना किसी मैन्युअल मरम्मत के काम जारी रख सकता है।
