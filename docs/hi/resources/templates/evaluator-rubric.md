# मूल्यांकन रूब्रिक (Evaluator Rubric)

कार्यान्वयन के बाद और अंतिम स्वीकृति से पहले इस रूब्रिक का उपयोग करें।

| श्रेणी | प्रश्न | स्कोर (0-2) | नोट्स |
| --- | --- | --- | --- |
| शुद्धता (Correctness) | क्या लागू किया गया व्यवहार अनुरोधित फ़ीचर से मेल खाता है? |  |  |
| सत्यापन (Verification) | क्या आवश्यक जाँचें वास्तव में सबूत के साथ चलीं? |  |  |
| दायरा अनुशासन (Scope discipline) | क्या सत्र चुने गए फ़ीचर दायरे के भीतर ही रहा? |  |  |
| विश्वसनीयता (Reliability) | क्या परिणाम बिना मरम्मत के रीस्टार्ट पर टिकता है? |  |  |
| रखरखाव (Maintainability) | क्या कोड और दस्तावेज़ अगले सत्र के लिए पर्याप्त रूप से स्पष्ट हैं? |  |  |
| हैंडऑफ तत्परता (Handoff readiness) | क्या कोई नया सत्र केवल रिपो आर्टिफैक्ट्स से काम जारी रख सकता है? |  |  |

## निर्णय (Verdict)

- स्वीकार करें (Accept)
- संशोधन करें (Revise)
- ब्लॉक करें (Block)
