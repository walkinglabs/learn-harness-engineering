# SOP: ऑब्ज़र्वेबिलिटी फीडबैक लूप (Observability Feedback Loop)

## उद्देश्य
एजेंट के निष्पादन को पारदर्शी बनाना और विफलताओं को स्वतः सुधारने के लिए रनटाइम सिग्नल्स का उपयोग करना।

## प्रक्रिया
1. **रनटाइम लॉग्स कैप्चर करें**: हर टूल कॉल और टेस्ट आउटपुट को स्ट्रक्चर्ड JSON में लिखें।
2. **स्प्रिंट कॉन्ट्रैक्ट्स का उपयोग करें**: हर टास्क से पहले स्कोप और पास क्राइटेरिया तय करें।
3. **स्वतंत्र चेकर से सत्यापन करवाएँ**: मेकर को कभी अपना काम खुद न जाँचने दें।
