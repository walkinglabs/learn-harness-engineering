# SOP: लेयर्ड डोमेन आर्किटेक्चर (Layered Domain Architecture)

## उद्देश्य
एजेंट-जनरेटेड कोडबेस में संरचनात्मक विचलन (drift) को रोकना और स्पष्ट निर्भरता प्रवाह सुनिश्चित करना।

## वास्तुकला परतें
- **Types**: डेटा संरचनाएँ और इंटरफेस
- **Config**: कॉन्फ़िगरेशन और एनवायरनमेंट वेरिएबल्स
- **Repo**: डेटा स्टोरेज और एक्सेस लेयर
- **Service**: मुख्य बिज़नेस लॉजिक
- **Runtime / API**: एंडपॉइंट्स और इवेंट हैंडलर्स
- **UI**: यूज़र इंटरफ़ेस और व्यू कंपोनेंट्स

नियम: निर्भरता केवल नीचे की परतों से ऊपर की ओर बह सकती है; कोई सर्कुलर डिपेंडेंसी अनुमत नहीं है।
