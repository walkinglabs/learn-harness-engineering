# कोडिंग एजेंट स्टार्टअप फ्लो (Coding Agent Startup Flow)

इनिशियलाइज़ेशन पूरा होने के बाद हर नए सेशन की शुरुआत में इस फ्लो का पालन करें।

## निश्चित स्टार्टअप क्रम (Fixed Startup Sequence)

1. `pwd` चलाएँ और पुष्टि करें कि आप सही रिपॉजिटरी रूट में हैं।
2. `claude-progress.md` पढ़ें।
3. `feature_list.json` पढ़ें।
4. `git log --oneline -5` से हाल के कमिट्स देखें।
5. `./init.sh` चलाकर एनवायरनमेंट की जाँच करें।
6. एक बेसलाइन स्मोक टेस्ट या एंड-टू-एंड टेस्ट चलाएँ।
7. यदि बेसलाइन टूटी हुई है, तो पहले उसे ठीक करें।
8. सर्वोच्च प्राथमिकता वाले अधूरे फ़ीचर को चुनें।
9. केवल उसी एक फ़ीचर (WIP=1) पर काम करें जब तक कि वह सत्यापित न हो जाए।

## यह क्रम क्यों महत्वपूर्ण है?

- `pwd` गलत डायरेक्टरी में काम करने से रोकता है।
- प्रोग्रेस और फ़ीचर फाइल्स नए बदलावों से पहले पुरानी स्टेट को रिकवर करती हैं।
- हाल के कमिट्स बताते हैं कि पिछले सत्र में क्या बदला था।
- `init.sh` मेमोरी पर निर्भर रहने के बजाय स्टार्टअप को मानकीकृत करता है।
- बेसलाइन वेरिफिकेशन टूटे हुए शुरुआती स्टेट को तुरंत पकड़ लेता है।

## सत्र का समापन दर्पण (End-Of-Session Mirror)

सत्र को इसी क्रम में समाप्त करना चाहिए:
1. प्रगति दर्ज करें
2. फ़ीचर स्थिति अपडेट करें
3. आवश्यकतानुसार हैंडऑफ लिखें
4. सुरक्षित कार्य कमिट करें
5. स्वच्छ रीस्टार्ट पाथ छोड़ें
