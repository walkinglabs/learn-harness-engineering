# इनिशियलाइज़र एजेंट प्लेबुक (Initializer Agent Playbook)

इस प्लेबुक का उपयोग तब करें जब आप किसी खाली रिपॉजिटरी या प्रोजेक्ट में पहली बार हार्नेस स्थापित कर रहे हों।

## इनिशियलाइज़ेशन क्रम (Initialization Sequence)

1. **टेम्पलेट से शुरुआत करें**: खाली जगह से शुरू करने के बजाय बेस प्रोजेक्ट टेम्पलेट कॉपी करें।
2. **डिपेंडेंसीज़ इंस्टॉल करें**: पैकेज मैनेजर लॉकफ़ाइल सत्यापित करें।
3. **कम से कम एक उदाहरण टेस्ट पास करें**: साबित करें कि टेस्ट फ्रेमवर्क काम कर रहा है।
4. **रूट निर्देश स्थापित करें**: `AGENTS.md` या `CLAUDE.md` बनाएँ।
5. **फ़ीचर सूची तैयार करें**: `feature_list.json` में शुरुआती फीचर्स जोड़ें।
6. **स्टार्टअप स्क्रिप्ट बनाएँ**: `init.sh` लिखें और एक्ज़ीक्यूटेबल बनाएँ।
7. **शुरुआती चेकपॉइंट कमिट करें**: स्वच्छ गिट कमिट करें।

## इनिशियलाइज़ेशन की स्वीकृति (Acceptance Criteria)

- [ ] `./init.sh` बिना किसी त्रुटि के चलता है
- [ ] बेसिक टेस्ट सूट पास होता है
- [ ] कोई भी नया एजेंट केवल फाइल्स देखकर काम समझ सकता है
