# प्रॉम्प्ट कैलिब्रेशन (Prompt Calibration)

एजेंट के आत्मविश्वास को वास्तविक सत्यापन साक्ष्यों से मिलाने के दिशानिर्देश:

## कैलिब्रेशन नियम (Calibration Rules)

1. **शब्दों पर भरोसा न करें**: जब तक कमांड आउटपुट 0 न दे, काम पूरा न मानें।
2. **सबूत माँगें**: हर दावे के पीछे टेस्ट लॉग या कमिट हैश होना चाहिए।
3. **त्रुटि संदेशों में सुधार निर्देश दें**: एजेंट को केवल गलती न बताएँ, उसे ठीक करने का पाथ दें।
4. **मेकर और चेकर को अलग रखें**: कोड लिखने वाले और जाँचने वाले को कभी एक न होने दें।
