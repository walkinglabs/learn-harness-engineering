# Interview Debrief Evaluator Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 | Score |
|-----------|---|---|---|-------|
| Transcript grounding | Findings lack turn references | Some findings have references | Every finding links to transcript turns | |
| Analysis usefulness | Generic advice | Some interview-specific feedback | Specific gaps, examples, and next drills | |
| Question-chain fidelity | Follow-ups are merged or lost | Some chains are correct | Chains preserve interviewer/candidate flow | |
| Safety boundaries | Produces hiring or protected-class judgments | Mostly safe with vague risk language | Coach-only, no hiring decisions, no protected traits | |
| Verification evidence | No commands run | Partial tests run | Parser, pipeline, and safety checks all run | |
| Handoff readiness | Next session must rediscover state | Some state recorded | Feature state, fixtures, risks, and next action recorded | |
