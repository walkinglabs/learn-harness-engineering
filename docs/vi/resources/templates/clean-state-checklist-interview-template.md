# Clean State Checklist

- [ ] `npm run check` passes.
- [ ] `npm test` passes against transcript fixtures.
- [ ] Full analysis pipeline was run on at least one representative transcript.
- [ ] Every report finding has transcript evidence references.
- [ ] Safety checker found no hiring-decision, protected-class, or fabricated-evidence language.
- [ ] `feature_list.json` reflects actual state.
- [ ] `session-handoff.md` records the next restartable action.
- [ ] Temporary transcripts, debug logs, and generated reports are either committed intentionally or removed.
